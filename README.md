Cloud Linux Security Posture Checker

A Bash-based Linux security automation tool designed to perform
basic security posture checks on a cloud/server environment.

## Features

- User identity validation
- Hostname validation
- System information collection
- Uptime collection
- Listening service visibility
- Basic security status reporting
- Input validation

## Technologies

- Bash
- Linux
- Vim
- ss

## Security Use Case

The tool provides a lightweight first-level security posture check
for Linux servers and cloud virtual machines.
